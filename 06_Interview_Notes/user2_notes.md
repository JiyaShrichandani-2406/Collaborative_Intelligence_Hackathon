# USER 2 — INTERVIEW NOTES

**Name:** Neha

**Task Discussed:** Drafting a response to a technical support query

---

## What We Discussed

The user was asked about how she normally handles a technical support query.

### Current Way of Working

* Reads the support query.
* Understands the customer's problem.
* Determines the information needed in the response.
* Drafts the response manually.
* Reviews it before finalizing.

### Difficulty / Repetitive Part

The same process has to be repeated for every support query, which makes response drafting a repetitive task.

### What Could Help

An AI-generated first draft could make the drafting stage faster, while the user could verify and make corrections before sending the response.
