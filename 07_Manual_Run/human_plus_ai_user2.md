# Human + AI Collaboration — User 2

I started with the AI-only response for the Salesforce case status issue and compared it with the human response and the original ticket.

The AI response was detailed and professional. It asked for useful information such as affected case numbers, status values, timestamps, and recent changes. However, it also listed many possible technical causes and troubleshooting steps before knowing which external system was involved or how the integration actually worked.

The human response focused first on understanding the integration. It asked which external system was connected, whether the update was real-time or scheduled, whether the integration was standard or customized, and which Salesforce feature was being used.

Based on this comparison, I used the AI response as the initial draft and applied the human's judgment to make it more focused. I removed unnecessary technical possibilities and kept the questions that are most useful for understanding the actual setup.

### Final Human + AI Output

Hello,

Thank you for reporting this issue.

We understand that some Salesforce case status updates are not syncing correctly with the external support system.

To understand the issue better, could you please provide:

* The external system integrated with Salesforce
* Whether the updates are real-time or scheduled
* Whether the integration is standard or customized
* Which Salesforce feature or integration is being used for the case updates
* A few examples of affected case numbers, if available

Once we have these details, we can better understand the setup and advise on the next steps.

Kind regards,
Support Team

### Collaboration Summary

**AI contribution:** Created the initial professional draft and suggested information and possible causes to investigate.

**Human contribution:** Focused the response on understanding the actual integration setup before making technical assumptions.

**Result:** AI helped with the initial drafting, while human judgment made the response more focused and relevant to the information available.
