# STEP 2: IMPACT METRIC

## Impact Metric

Time required to draft a client response for one technical support query.

## Unit

Minutes per support query

## Baseline Measurement

The same technical support ticket was used to compare the response-drafting time of a technical support employee and a plain LLM.

| Method                     | Time to Draft Response |
| -------------------------- | ---------------------: |
| Technical Support Employee |              5 minutes |
| Plain LLM                  |              5 seconds |

## Measurement Method

The timer was started when the response-drafting task began and stopped when the response was ready.

The same support ticket was provided to both the technical support employee and the plain LLM so that the response-drafting time could be compared under the same input.

## Initial Finding

For the tested support ticket, the technical support employee took **5 minutes** to draft a response, while the plain LLM took **5 seconds**.

This shows a significant difference in response-drafting speed between the human-only and plain-LLM approaches.

## Purpose of the Metric

This metric will be used to determine whether a **collaborative human + AI workflow** can reduce the time required to prepare a client response while keeping human judgement and verification in the process.
